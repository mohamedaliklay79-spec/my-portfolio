Flavora

A recipe app for browsing, saving and adding recipes, built with React Native and a custom REST API backed by MongoDB.

React Native TypeScript Node.js Express MongoDB

Overview

Flavora is a mobile recipe app. Users browse recipes by category, open a recipe to see its details, save favorites, and add their own recipes.

The app talks to a REST API I built with Node.js and Express, which stores all recipe data in MongoDB. The mobile client and the API live in the same repository.

Features

  • RecipesBrowse a list of recipes and open any one for full details.
  • CategoriesFilter recipes by category to find what you want faster.
  • FavoritesSave the recipes you like and come back to them.
  • Add recipesCreate your own recipes from inside the app.

How it's built

Mobile app

React Native with TypeScript. Screens call the API through a small client module and render the results.

Backend API

Node.js and Express. REST endpoints for recipes, categories and favorites.

Database

MongoDB stores the recipes and their related data.
